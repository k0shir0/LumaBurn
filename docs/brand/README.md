# LumaBurn banner

`lumaburn-logo.png` is the README banner: 1920 × 440 pixels, with a white
background, navy Luma (`#142b38`), and mint Burn/disc (`#6fc7ae`).

The editable source is `lumaburn-logo.svg`. Export it at its native size in a
browser with Arial Bold installed so the PNG preserves the actual lettering.
