    Prepare or burn media
    1. Add files on Media. Every new file starts selected; uncheck a file to leave it out of output. Selected queue order is the DVD title order.
    2. Choose a format and destination on Output. Detected recorders and writable USB drives are selected automatically; you can change them. Gentle computer usage keeps other apps responsive; Full speed uses more CPU.
    3. Choose Burn DVD to convert the selected videos, author DVD-Video, write and finalize a blank DVD, and verify its contents. Save ISO only exports a disc image without writing to the disc. Other formats prepare or copy files.
    4. Follow overall and phase progress on Activity, then open the output folder. A phase may restart its own percentage; overall progress tracks the project. Unknown progress is labeled explicitly.
    First launch
    Install Python 3.11 or newer, enable Add Python to PATH, then double-click Launch.cmd. LumaBurn automatically prepares missing FFmpeg, FFprobe, and DVD authoring tools. Download progress appears at the top of the app; select Retry setup there if a download fails. First setup needs internet access and 64-bit Intel/AMD Windows. Later launches reuse the tools offline.
    Tool setup verifies downloads and extracts them locally without running an installer. Check Devices for availability. For an existing custom installation, set LUMABURN_FFMPEG, LUMABURN_FFPROBE, or LUMABURN_DVDAUTHOR, then restart LumaBurn. Tools on PATH and installed DVDStyler are also detected. Windows provides disc-writing support; burning needs an optical writer and compatible blank media.
    7-Zip and WinRAR are optional for archive estimates. Built-in LZMA works without either program. Original copies and data discs need no conversion tools and remain available if tool setup fails.
    Compression estimates
    Browse a file or folder on Media and estimate with the maximum compression level. Sampling and memory limits keep the estimate responsive; a full archive may compress differently. The estimate reports expected size and savings without creating an archive. Videos, audio, and existing archives often have little room to shrink. Use the installed archiver to create an archive.
    Playback and discs
    DVD video prepares an authored VIDEO_TS folder and ISO that auto-play selected titles in order without a menu. Data discs keep the original files. USB video uses H.264 MP4; check your player’s format and USB filesystem support. Burning accepts blank writable discs only and finalizes them. Disc writing cannot be interrupted safely.
    Use Tests to check drive visibility and a readable DVD structure. This does not prove physical DVD-player playback or read every byte of a full movie.
